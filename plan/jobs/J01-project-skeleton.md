## Spec

**Project settings.** Physics interpolation on. Physics tick 60. Window 1600 × 900, stretch mode `canvas_items`, aspect `keep`. Rendering: Forward+, MSAA 2×. Collision layer names: 1 world, 2 player_body, 3 enemy_body, 4 player_hurtbox, 5 enemy_hurtbox, 6 player_hitbox, 7 enemy_hitbox, 8 projectile, 9 interactable, 10 world_item.

**Input map.** Actions: `move_up` W, `move_down` S, `move_left` A, `move_right` D, `attack_basic` LMB, `skill_1` RMB, `skill_2` key 1, `skill_3` key 2, `dodge` Space, `interact` E, `inventory` I, `character` C, `journal` J, `pause` Esc, `debug_console` F1, `debug_cycle_weapon` Tab.

**Autoloads.** `EventBus` declares the signals other jobs will emit. Start with: `enemy_died(enemy: Node)`, `player_died`, `item_picked_up(item)`, `quest_updated(quest_id: StringName)`, `quest_completed(quest_id: StringName)`, `flag_set(flag: StringName)`, `world_state_changed(state: int)`, `zone_entered(zone_id: StringName)`, `dialogue_started(npc_id)`, `dialogue_ended(npc_id)`. Later jobs add to this file; keep it the single list. `GameState` holds `phase: int = 1`, `flags: Dictionary`, `set_flag(name)`, `has_flag(name)`, `current_zone: StringName`, and emits `flag_set`. `WorldState` holds `enum State { DAY, FOG }` and `state` with a setter that emits `world_state_changed`; the rest is J11. `SaveSystem` is an empty class with `save()` and `load()` returning false; J19 fills it.

**Palette generation.** `tools/gen_palette_gd.ps1` reads `design/palette.json` and writes `game/core/palette.gd` containing: `const DAY: Dictionary` and `const FOG: Dictionary` mapping role name to `Color` for ramp, environment, accents and UI signals; `static func role(name: StringName, state: int) -> Color` that falls back to DAY when a role only exists there; and a header comment "generated, do not edit". Re-running the script must be idempotent. Add the command to `game/README.md`.

**Graybox kit.** Materials as `.tres`: `mat_gray.tres` (palette day ramp mid), `mat_frost.tres` (fog lichen tint), `mat_highlight.tres` (day sun), `mat_rarity_common/fine/rare/legendary.tres`. Scenes: `box_actor.tscn` (MeshInstance3D BoxMesh plus a smaller nose box on +Z, `@export var size_class` with an enum PLAYER, SMALL, MEDIUM, LARGE, BOSS, TROLL applying the sizes from the gdd placeholder policy), `box_prop.tscn` (box with StaticBody3D collision), `ground_plane.tscn` (PlaneMesh 60 × 60 with StaticBody3D). A `Graybox` static helper with `func make_box(size: Vector3, material) -> MeshInstance3D`.

**Test arena.** `game/test/arena.tscn`: ground plane, a dozen props as walls and pillars, DirectionalLight3D at 45° with the day sun colour, WorldEnvironment with ambient from palette day sky, a `Marker3D` named `PlayerSpawn`. It runs and shows a lit gray scene.

**GUT.** Install GUT compatible with Godot 4.7 into `game/addons/gut`, enable the plugin, set the test directory to `res://test/unit`, add `test_example.gd` asserting `Palette.DAY.has("moss")`.

**Git.** If the repo root is not yet a git repository, `git init` it on branch `main`. If it already is (the design and plan may have been committed before this job), work on a branch `job/J01-project-skeleton` and merge to `main` when done. Either way make sure `.gitignore` contains `game/.godot/`, `game/export/`, `*.tmp`, `.DS_Store`, `Thumbs.db`, and keep `*.import` files tracked. Commit message "J01: project skeleton".
