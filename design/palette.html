mashuprpg4 forest palette

Two states of the same forest. Every new colour in the game is picked from these by role. Source of truth: palette.json.

Reference

Day Dagsljus

Sunlit Swedish pine forest. Warm olive-gold ground, orange pine bark, one cool colour: the sky.

Fog Dimma

The same forest with the other world showing through. One cold blue-slate ramp, near-black shadows, and a few saturated accents that are the only colour left.
